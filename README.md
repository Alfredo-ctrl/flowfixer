## Existing Project Notes

# FlowFixer

FlowFixer is an offline debugging assistant for students and developers.

Paste an error, stack trace, terminal log, or bug description. FlowFixer turns it into a clear route:

- What the error probably means.
- Likely causes.
- Debug checklist.
- Commands to try.
- A clean report you can copy or export.
- Local history of solved debugging cases.

No API key, login, or internet connection is required.

## Run

Open `index.html` directly, or run:

```bash
npm run serve
```

Then visit:

```text
http://127.0.0.1:5308
```

## Why it exists

Most developers lose time because an error feels bigger than it is. FlowFixer helps break the panic into a path: read, isolate, test, fix, verify, and document.
